Directory Organizer
A bash script that automatically organizes files in a folder by moving them into subfolders based on their file extension.
How It Works
Text files go into the docs folder. Shell scripts go into the scripts folder. Log files go into the logs folder. Everything else goes into the misc folder.
How To Run It
bash organizer.sh
What I Learned
Built this as part of my Linux sysadmin study journey. Practiced bash variables, for loops, if statements, and case statements.
